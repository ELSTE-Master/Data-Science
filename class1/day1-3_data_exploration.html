TipPackages, modules and functions

Python’s capabilities can be extended by importing packages. A package groups related tools and can contain modules, which organise code into separate components. These tools include functions, which perform particular tasks.

In the following example:

Function reference: read_csv (doc).

import pandas as pd
df = pd.read_csv('data.csv')
  • pandas is the package we import.
  • pd is the short name we choose to refer to it.
  • read_csv() (doc) is a function provided by pandas.
  • 'data.csv' is an argument telling the function which file to read.
  • df is the variable in which we store the resulting DataFrame.

Later, we will also call methods: functions associated with an object, such as df.head() (doc).

Basic data exploration

Let’s now explore the structure of the dataset with the following functions:

Function Description
df.head() (doc) Prints the first 5 rows of the DataFrame
df.tail() (doc) Prints the last 5 rows of the DataFrame
df.info() (doc) Displays some info about the DataFrame, including the number of rows (entries) and columns. Note the Dtype column: this is the type variable stored in each column including strings (object), integer (int64) and float (int64) numbers. See that the Date column is indeed stored as a datetime variable as requested above.
df.shape (doc) Returns a list containing the number of rows and columns of the DataFrame.
df.index (doc) Returns a list containing the index along the rows of the DataFrame.
df.columns (doc) Returns a list containing the index along the columns of the DataFrame.
TipWhy do some expressions have parentheses?

Compare these two expressions:

Function reference: head (doc); shape (doc).

df.head()
df.shape

head() (doc) is a method: we call it with parentheses to perform an operation. We can also pass arguments, such as df.head(3) (doc) to display the first three rows.

shape (doc) is an attribute: we access it without parentheses to obtain information about the DataFrame. It returns a pair of numbers: the number of rows and the number of columns.

The same distinction applies to df.info() (doc) and df.tail() (doc)—methods—and to df.index (doc) and df.columns (doc)—attributes.

Sorting data

The main function to sort data is .sort_values (doc). It is necessary to review how three arguments can alter the function’s behaviour:

  1. by: First argument (required) is the label of index/row used to sort the data. It is possible to sort by multiple columns by passing a list of values.
  2. axis: Specifies whether sorting rows (axis = 0 - in which case by is a column name) or sorting columns (axis = 1, in which case by is an index value). The documentation specifies axis = 0, which means that rows will be sorted if axis is not specified.
  3. ascending: Using a bool (remember, this is a True/False behaviour), specifies if values are sorted in ascending (ascending = True, default behaviour is not specified) or descending (ascending = False) order.
