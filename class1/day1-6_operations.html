Operations

Data management operations

Pandas contains several helpful functions to manage and format numerical data (Table 1).

ImportantStore the result if you want to keep it

Many pandas operations return a transformed result without changing the original data. For example:

Function reference: round (doc).

df['Latitude'].round(2)

This returns latitude values rounded to two decimal places, but the original Latitude column remains unchanged.

To replace the original values, assign the result back:

Function reference: round (doc).

df['Latitude'] = df['Latitude'].round(2)

To preserve the original values, store the result in a new column instead:

Function reference: round (doc).

df['Latitude_rounded'] = df['Latitude'].round(2)

Before assigning a result, decide whether you want to update the original data or keep a separate version.

TipFilling missing data

The .fillna (doc) example in Table 1 shows how to replace missing data - often referred to as Nan for Not a number - with 0 value. However, Pandas’s .fillna (doc) contains a lot of different methodologies to fill missing values (e.g., interpolation). Again, take the habit of checking out the documentation of the functions your frequently use.

Longitudes are expressed as degrees E (i.e., from 0–180 ) and degrees W (i.e., from -180–0). Use operators to convert longitudes to degrees E (i.e., from 0–360) and store the results to a column called Longitude_E. To do so:

  1. Define a mask where Longitudes are negative using [logical operators]
  2. Where the mask is True (i.e. where the longitude is negative), add the longitude (or subtract its absolute value) to 360
TipDefine a mask

Start by defining a mask

TipHow? 
mask = df['Longitude'] <= 0
TipSelect the values

Select the values using .loc (doc) and do the maths.

TipHow?

Function reference: loc (doc).

360 + df.loc[mask, 'Longitude']
TipStore back the values

Function reference: loc (doc).

df.loc[mask, 'Longitude_E'] = 360 + df.loc[mask, 'Longitude']
