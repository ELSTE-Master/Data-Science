Database What can you find?
PANGAEA About 447,000 datasets: marine geology, geochemistry, palaeoclimate and ecology. Documented datasets with citable DOIs.
EarthScope Continuous seismic records from thousands of stations. 590 TB archived by 2019; over 215 TB of new geophysical data in 2024.

Open Earth-observation data

Database What can you find?
Landsat Over 13.8 PB of imagery since 1972. About 1 TB/day of new observations and 3 TB/day of derived scientific products.
Copernicus Sentinel Radar, optical and atmospheric observations. Sentinel 1 & 2 acquire 4.6 TB/day; the former portal distributed about 590 PB to 750,000 users before closing in 2023.
NASA EOSDIS Observations of the atmosphere, oceans, ice, biosphere and land. Higher-resolution missions drive archive growth and analysis in the cloud.
ERA5 Hourly global climate reanalysis: 200+ variables on an approximately 31 km grid. About 5 PB of native data and 1 PB prepared for distribution.
NOAA NCEI Open weather, ocean, coastal and geophysical archives from historical records, stations, buoys, ships and other observing systems.

What is Python

High-level computing language

  • Compiled → doesn’t directly speak to the computer, but is interpreted by another language
    • Usually slower, but much, much easier to use!

Modular

  • Python is composed of a core of functions complemented by wide ecosystem of specialized packages for specific tasks
    • A function is a bit of code to perform a specific task
    • A module is a collection of functions
    • A package is composed by multiple modules

An example of packages, modules and functions

How to approach coding

Python as a natural language

Natural language Python Example
Noun Object or variable df
Verb Function or method mean(), sort_values()
Complement Target variable "altitude"
Adverb Argument specifying how ascending=False
Sentence Instruction df.sort_values(...) 
df.sort_values("altitude", ascending=False)

Python checks the grammar of your code. You must check the scientific meaning of the sentence.

This is an analogy, not an exact grammatical correspondence. A variable refers to an object, and an argument can specify both what to work on and how to perform an operation.

Ask students to identify the table, the action, the target column and the direction of sorting. Then change ascending=False to ascending=True and have them explain the new instruction before running it.

Connect this to the teaching dataset: sorting by VEI orders the recorded eruption classes; it does not establish which volcano or country is most hazardous.

From a sentence to a sequence of tasks

 

Task Questions to ask
Load Where are the data? How do I read them?
Inspect What do the rows, columns and values represent?
Select / filter Which columns and observations do I need?
Transform What should I sort, recode or calculate?
Summarise / analyse What quantity or relationship answers my question?
Visualise / export How should I show or save the result?

These are practical categories, not a rigid sequence: an analysis often loops back to inspection or selection.

Translate the scientific question into small tasks in plain language, then choose a function for each task. Here, the data have already been loaded. Filter with a Boolean mask, select columns with .loc, and sort with .sort_values(). Not every question requires all six categories.

Ask students to identify which tasks require pandas and which will later require plotting or statistical libraries. After each step, inspect the result and check that it still represents the observations you intended to analyse.

Anatomy of a DataFrame

  • Similar to Excel → contains tabular data composed of rows and columns

  • In Excel:

    • Rows are accessed using numbers
    • Columns are accessed using letters

Anatomy of a DataFrame

  • Unlike Excel, rows and columns can be labelled
    • Index refers to the label of the rows. In the index, values are usually unique - meaning that each entry has a different label.
    • Column refers to the label of - logically - the columns
