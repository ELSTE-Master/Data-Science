Pandas

This reference explains the Pandas tools used in classes 1–4. Each entry gives a purpose, the arguments most useful in this course, an example, and a practical note. Follow Official documentation for the complete API.

Examples use the course datasets: df is the eruption table, df_traces the geochemical table, reading the reading-score table, and df_icecover the lake table. Samples such as dietA and dietB have already been selected. Variables such as data, ax, and mod1 refer to the array, axes, or fitted model described in the lesson. Snippets illustrate individual operations rather than forming a script to run from top to bottom.

Import pandas as pd. Methods use parentheses, such as df.head(); attributes such as df.shape do not. Indexers .loc and .iloc use square brackets. Many transformations return a result: assign it if you want to keep it.

read_csv()

Purpose: Read a CSV file into a DataFrame.

Main arguments: filepath_or_buffer: path or URL; parse_dates: column names to interpret as dates; sep: field separator.

Example:

df = pd.read_csv('data/dummy_volcanoes.csv', parse_dates=['Date'])

Remember: Check the column names and types after loading.

Official documentation

read_excel()

Purpose: Read a worksheet from an Excel file.

Main arguments: io: file path; sheet_name: worksheet name or position.

Example:

df = pd.read_excel('geochemistry.xlsx', sheet_name='Supp_traces')

Remember: Use read_csv() for the CSV versions supplied in the course.

Official documentation

DataFrame()

Purpose: Create a labelled table from columns or records.

Main arguments: data: dictionary, array or records; index: optional row labels.

Example:

new_data = pd.DataFrame({'age': [6, 8, 10], 'group': 'Control'})

Remember: Columns used for prediction must match those in the model formula.

Official documentation

Categorical()

Purpose: Represent a variable as categories rather than continuous numbers.

Main arguments: values: observations; categories: optional allowed categories; ordered: whether their order has meaning.

Example:

df_icecover['lakeid'] = pd.Categorical(df_icecover['lakeid'])

Remember: A numeric code can still represent a category.

Official documentation

cut()

Purpose: Divide numerical values into intervals.

Main arguments: x: values; bins: interval boundaries or number of intervals; labels: optional interval labels.

Example:

binned = pd.cut(df_traces['Zr'], bins=[0, 100, 200, 300])

Remember: The chosen boundaries affect the resulting categories.

Official documentation

head()

Purpose: Display the first rows.

Main arguments: n: number of rows; default is 5.

Example:

df.head(3)

Remember: A preview does not describe every observation.

Official documentation

tail()

Purpose: Display the last rows.

Main arguments: n: number of rows; default is 5.

Example:

df.tail(5)

Remember: Useful for checking the end of a file.

Official documentation

info()

Purpose: Print column types and non-missing counts.

Main arguments: Usually no arguments are needed.

Example:

df.info()

Remember: Prints a summary; its return value is not the summary table.

Official documentation

set_index()

Purpose: Use one or more columns as row labels.

Main arguments: keys: column name or names.

Example:

df = df.set_index('Name')

Remember: Store the returned DataFrame; labels need not be unique.

Official documentation

reset_index()

Purpose: Restore a sequential row index.

Main arguments: drop: discard the old index instead of keeping it as a column.

Example:

df = df.reset_index()

Remember: By default, the former index becomes a column.

Official documentation

sort_values()

Purpose: Sort observations by one or more columns.

Main arguments: by: column names; ascending: increasing or decreasing order.

Example:

df = df.sort_values(['VEI', 'Date'], ascending=False)

Remember: Sorting returns a new result unless explicitly performed in place.

Official documentation

round()

Purpose: Round numbers to a chosen number of decimal places.

Main arguments: decimals: number of decimal places.

Example:

df['Latitude_rounded'] = df['Latitude'].round(2)

Remember: Decimal places are different from significant figures.

Official documentation

abs()

Purpose: Take the absolute value of each number.

Main arguments: No arguments are needed.

Example:

distance = df['Latitude'].abs()

Remember: Useful when the size of an offset matters more than its sign.

Official documentation

apply()

Purpose: Apply a function to values or rows/columns.

Main arguments: func: function to apply; DataFrame axis=0 works by column and axis=1 by row.

Example:

rounded_down = df['Latitude'].apply(np.floor)

Remember: Passing a function is different from calling it immediately.

Official documentation

clip()

Purpose: Limit values to a lower and/or upper bound.

Main arguments: lower, upper: allowed bounds.

Example:

bounded = df['Latitude'].clip(lower=-90, upper=90)

Remember: Clipping changes values; it is not a substitute for investigating errors.

Official documentation

fillna()

Purpose: Replace missing values.

Main arguments: value: replacement value.

Example:

filled = df['VEI'].fillna(0)

Remember: Zero is an observed value, not a neutral replacement for missing data. Interpolation uses a separate method.

Official documentation

mean()

Purpose: Compute an arithmetic mean.

Main arguments: axis=0: by column; axis=1: by row; skipna: ignore missing values.

Example:

df_traces[['Rb', 'Sr']].mean(axis=0)

Remember: Only average comparable quantities; outliers can strongly affect the mean.

Official documentation

median()

Purpose: Compute the middle value of sorted observations.

Main arguments: axis: direction of the summary; skipna: ignore missing values.

Example:

df_traces['Zr'].median()

Remember: For an even number of observations, the median averages the two middle values.

Official documentation

mode()

Purpose: Return the most frequent value or values.

Main arguments: dropna: whether to exclude missing values.

Example:

df_traces['Zr'].mode()

Remember: May return several values; exact modes can be uninformative for continuous measurements.

Official documentation

min()

Purpose: Find the smallest observed value.

Main arguments: axis: direction of the summary; skipna: ignore missing values.

Example:

df_traces['Zr'].min()

Remember: The sample minimum is not necessarily the population minimum.

Official documentation

max()

Purpose: Find the largest observed value.

Main arguments: axis: direction of the summary; skipna: ignore missing values.

Example:

df_traces['Zr'].max()

Remember: The sample maximum is not necessarily the population maximum.

Official documentation

var()

Purpose: Estimate variance using squared deviations from the mean.

Main arguments: ddof: denominator is sample size minus ddof; pandas defaults to 1.

Example:

df_traces['Zr'].var()

Remember: Variance has squared units; select numerical columns.

Official documentation

std()

Purpose: Estimate standard deviation.

Main arguments: ddof: pandas defaults to 1; axis: direction of the summary.

Example:

df_traces[['Rb', 'Sr']].std()

Remember: Standard deviation has the same units as the measurements.

Official documentation

skew()

Purpose: Estimate the asymmetry of a distribution.

Main arguments: axis: direction of the summary; skipna: ignore missing values.

Example:

df_traces['Zr'].skew()

Remember: Positive values indicate a longer right tail; inspect the distribution as well.

Official documentation

cov()

Purpose: Compute pairwise sample covariances.

Main arguments: min_periods: minimum number of paired observations; ddof: degrees-of-freedom adjustment.

Example:

df_traces[['Rb', 'Sr', 'Zr']].cov()

Remember: Magnitude depends on the variables’ units and scales.

Official documentation

corr()

Purpose: Compute pairwise correlations.

Main arguments: method: Pearson, Spearman or Kendall; min_periods: minimum paired observations.

Example:

df_traces[['Rb', 'Sr', 'Zr']].corr(method='pearson')

Remember: Correlation does not establish causation; Pearson measures linear association.

Official documentation

groupby()

Purpose: Split observations into groups for subsequent summaries.

Main arguments: by: column name or list of names.

Example:

df_traces.groupby('Epoch')[['Rb', 'Sr']].mean()

Remember: Returns a GroupBy object; follow it with a summary such as mean().

Official documentation

drop()

Purpose: Remove selected rows or columns.

Main arguments: labels: names to remove; columns: column names.

Example:

numerical = df_traces_sub.drop(columns=['Epoch'])

Remember: By default the returned table must be assigned if you want to retain it.

Official documentation

astype()

Purpose: Convert the stored type of a column or table.

Main arguments: dtype: target type.

Example:

df_icecover['year'] = df_icecover['year'].astype(int)

Remember: Conversion fails when values cannot be represented by the requested type.

Official documentation

unique()

Purpose: Return distinct values in a Series.

Main arguments: No arguments are needed.

Example:

reading['group'].unique()

Remember: Preserves first-appearance order; it does not sort or count the values.

Official documentation

map()

Purpose: Replace or transform each value in a Series.

Main arguments: arg: mapping dictionary or function.

Example:

colours = reading['group'].map({'Control': 'blue', 'Treatment': 'orange'})

Remember: Values absent from a dictionary mapping become missing.

Official documentation

get()

Purpose: Retrieve a labelled value with a fallback.

Main arguments: key: label; default: value returned when the label is missing.

Example:

b_group = mod1.params.get('group[T.Treatment]', 0)

Remember: A fallback is useful only when its meaning is justified.

Official documentation

shape

Purpose: Read the number of rows and columns.

Main arguments: This is an attribute: do not add parentheses.

Example:

rows, columns = df.shape

Official documentation

index

Purpose: Read row labels.

Main arguments: This is an attribute: do not add parentheses.

Example:

labels = df.index

Official documentation

columns

Purpose: Read column labels.

Main arguments: This is an attribute: do not add parentheses.

Example:

names = df.columns

Official documentation

dtypes

Purpose: Read the stored type of each column.

Main arguments: This is an attribute: do not add parentheses.

Example:

types = df.dtypes

Remember: Types stored in Python and scientific variable types are different concepts.

Official documentation

loc

Purpose: Select rows and columns by labels or a Boolean mask.

Main arguments: Use square brackets: row_selection, column_selection.

Example:

selected = df.loc[['Calbuco', 'Taal'], ['Country', 'VEI']]

Remember: Use : to retain all rows or columns; label slices include their endpoint.

Official documentation

iloc

Purpose: Select rows and columns by integer position.

Main arguments: Use square brackets: row positions, then column positions.

Example:

selected = df.iloc[0:5, 1:3]

Remember: Positions start at zero; the end of a slice is excluded.

Official documentation

str.contains()

Purpose: Test whether text contains a pattern.

Main arguments: pat: text or regular expression; regex=False: literal text; na=False: treat missing values as non-matches.

Example:

mask = df['Country'].str.contains('I', regex=False, na=False)

Remember: The examples using a Name column require that it has not been moved to the index.

Official documentation

str.startswith()

Purpose: Test whether text starts with a prefix.

Main arguments: pat: prefix; na: result for missing values.

Example:

mask = df['Country'].str.startswith('I', na=False)

Official documentation

str.endswith()

Purpose: Test whether text ends with a suffix.

Main arguments: pat: suffix; na: result for missing values.

Example:

mask = df['Country'].str.endswith('a', na=False)

Official documentation

str.len()

Purpose: Count the characters in each string.

Main arguments: No arguments are needed.

Example:

lengths = df['Country'].str.len()

Remember: This is different from Python len(), which counts elements in the Series.

Official documentation

str.upper()

Purpose: Convert text to uppercase.

Main arguments: No arguments are needed.

Example:

upper = df['Country'].str.upper()

Remember: Store the result if you want to retain it.

Official documentation

str.lower()

Purpose: Convert text to lowercase.

Main arguments: No arguments are needed.

Example:

lower = df['Country'].str.lower()

Remember: Useful when normalising text before comparisons.

Official documentation

str.replace()

Purpose: Replace part of each string.

Main arguments: pat: text to find; repl: replacement; regex=False: literal replacement.

Example:

renamed = df['Country'].str.replace('USA', 'United States', regex=False)

Remember: Use ordinary Series map() when replacing complete category labels.
