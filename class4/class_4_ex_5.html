Exercise 5: AIC and five-fold cross-validation

Extension activity: complete this page if you have time after the first four exercises. We will compare the three models from the lecture, using only training observations:

  1. MgO-only linear regression;
  2. a linear model with three oxides;
  3. a full three-oxide quadratic with squared terms and pairwise interactions.

Model selection uses the training data (train). The separate test dataset (evaluation) is not used to fit or choose models here.

AIC rewards better fit while penalizing model complexity. Smaller AIC is preferred among these candidate models. AIC is not a prediction error in degrees Celsius.

Question 1 — What does AIC measure?

Question 2 — Calculate AIC on training data

selection_formulas() supplies the three model formulas from the lecture. Complete the code to fit each model on the training data, calculate AIC and subtract the smallest AIC. The model with the smallest AIC will have a difference of zero.

  • Exercise
  • Hints
  • Solution

The model uses train. The fitted result’s .aic property contains AIC, and .min() obtains the smallest value in the Series.

from cpx_lesson import load_data, selection_formulas
import statsmodels.formula.api as smf
import pandas as pd

train, _ = load_data()
aic = {}
for name, formula in selection_formulas().items():
    fit = smf.ols(formula, data=train).fit()
    aic[name] = fit.aic

scores = pd.Series(aic)
delta_aic = scores - scores.min()
print(delta_aic.round(1).to_string())

Question 3 — Why cross-validation too?

Five-fold cross-validation checks predictions using the training data:

  1. Divide the training observations into five parts, called folds.
  2. Fit the model using four folds.
  3. Predict the observations in the remaining fold, which was not used for that fit.
  4. Repeat until each fold has been used to evaluate predictions once.
  5. Combine all these prediction errors to calculate a cross-validation RMSE.

The original test dataset stays outside this procedure. Why is cross-validation useful alongside AIC?

Question 4 — Calculate five-fold cross-validation RMSE

cv_folds(train) provides the five predefined folds, labelled 0 to 4. You do not need to create or change them. In the loop, fitting contains four folds and validation contains the remaining fold.

Complete the code for the three-oxide model. Collect the squared prediction errors from all five validation folds, then take their mean and its square root to obtain the cross-validation RMSE.

  • Exercise
  • Hints
  • Solution

Fit on fitting and predict validation. Use np.mean() to pool the squared errors. The result should be close to the lecture’s three-oxide CV RMSE of 90.1 °C.

from cpx_lesson import load_data, cv_folds
import statsmodels.formula.api as smf
import numpy as np

train, _ = load_data()
fold = cv_folds(train)
formula = "T_C ~ MgO_Cpx + Al2O3_Cpx + TiO2_Cpx"
squared_errors = []

for v in range(5):
    fitting = train.loc[fold != v]
    validation = train.loc[fold == v]
    model = smf.ols(formula, data=fitting).fit()
    error = validation["T_C"] - model.predict(validation)
    squared_errors.extend((error ** 2).to_numpy())

cv_rmse = np.sqrt(np.mean(squared_errors))
print(f"5-fold CV RMSE: {cv_rmse:.1f} °C")
