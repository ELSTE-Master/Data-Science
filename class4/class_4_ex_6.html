Question 2 — Compute classical intervals in Python

As in the slides, choose the MgO value at which the fitted simple model predicts 1,200 °C. Complete the call to statsmodels, then compare the interval widths.

  • Exercise
  • Hints
  • Solution

Call .get_prediction(new) followed by .summary_frame(alpha=0.05). mean_ci_* refers to the mean response, while obs_ci_* refers to an individual outcome.

from cpx_lesson import load_data
import statsmodels.formula.api as smf
import pandas as pd

train, _ = load_data()
simple = smf.ols("T_C ~ MgO_Cpx", data=train).fit()
b0, b1 = simple.params
x0 = (1200 - b0) / b1
new = pd.DataFrame({"MgO_Cpx": [x0]})

intervals = simple.get_prediction(new).summary_frame(alpha=0.05)
row = intervals.iloc[0]
mean_width = row["mean_ci_upper"] - row["mean_ci_lower"]
individual_width = row["obs_ci_upper"] - row["obs_ci_lower"]
print(row[["mean", "mean_ci_lower", "mean_ci_upper",
           "obs_ci_lower", "obs_ci_upper"]].round(1).to_string())
print(f"Mean CI width: {mean_width:.1f} °C")
print(f"Individual PI width: {individual_width:.1f} °C")

Question 3 — Why is the individual interval wider?

Question 4 — Optional: inspect empirical interval coverage

The classical intervals rely on a correctly specified conditional mean and independent, normal, constant-variance errors. These assumptions may be questionable for observations clustered by publication.

As a descriptive exercise only, estimate how often the simple model’s nominal 95% individual prediction intervals contain the measured temperatures in the frozen evaluation partition. This does not validate coverage for natural crystals or for all future publications.

  • Exercise
  • Hints
  • Solution

A Boolean array contains True for covered observations. Its .mean() or np.mean() gives the fraction covered. The arrays, rather than pandas indexes, are compared to preserve their observation order.

from cpx_lesson import load_data
import statsmodels.formula.api as smf
import numpy as np

train, evaluation = load_data()
simple = smf.ols("T_C ~ MgO_Cpx", data=train).fit()
frame = simple.get_prediction(evaluation).summary_frame(alpha=0.05)
low = frame["obs_ci_lower"].to_numpy()
high = frame["obs_ci_upper"].to_numpy()
observed = evaluation["T_C"].to_numpy()

covered = (observed >= low) & (observed <= high)
fraction = np.mean(covered)
print(f"Evaluation fraction inside nominal 95% PIs: {fraction:.3f}")
