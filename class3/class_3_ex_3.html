Exercises magma data: ANOVA

In the lecture and in the previous exercises, we compared two crustal-thickness classes at a time. We now consider the three classes together, as in the last slides of the lecture. Following Farner & Lee (2017), our theory is that magmatic differentiation increases with crustal thickness, i.e.

\[\mu_{\text{thin}} < \mu_{\text{medium}} < \mu_{\text{thick}},\]

where \(\mu_{\text{thin}}\), \(\mu_{\text{medium}}\) and \(\mu_{\text{thick}}\) denote the mean SiO\(_2\) content (wt.%) of magmas erupting through thin (\(< 30\) km), medium (\(30\)–\(43\) km) and thick (\(\geq 43\) km) crust. We use the same random subsample of \(60\) cells per class as in the lecture and follow the standard procedure in two steps:

  1. Step 1: a multiple-sample location test of \(H_0\): “the three means are equal”. If \(H_0\) is not rejected, we stop here.

  2. Step 2: otherwise, three one-sided Welch’s t-tests (thin vs medium, medium vs thick and thin vs thick) at a corrected significance level \(\alpha_c\), hoping to reject \(H_0\) each time.

As always, we start by looking at the data. The code below (the same as in the lecture) loads the data and draws the boxplots of the three groups.

Function reference: read_csv (doc); plt.figure (doc); ax.boxplot (doc); dict (doc); enumerate (doc); np.random.normal (doc); ax.scatter (doc); ax.set_ylabel (doc); plt.show (doc).

# Import data
import pandas as pd
crust = pd.read_csv("https://raw.githubusercontent.com/ELSTE-Master/Data-Science/main/Data/arc_magmas_crust_sample.csv")

# Variables of interest
sio2_thin   = crust["sio2"][crust["crust_class"] == "thin"]
sio2_medium = crust["sio2"][crust["crust_class"] == "medium"]
sio2_thick  = crust["sio2"][crust["crust_class"] == "thick"]
import matplotlib.pyplot as plt
import numpy as np

plt.figure(figsize=(6, 4))
plt.boxplot([sio2_thin, sio2_medium, sio2_thick],
            tick_labels=["Thin crust", "Medium crust", "Thick crust"],
            patch_artist=True,
            boxprops=dict(facecolor="lightblue", color="blue"),
            medianprops=dict(color="red"),
            showfliers=False)  # the points are drawn individually below
for i, data in enumerate([sio2_thin, sio2_medium, sio2_thick], start=1):
    x = np.random.normal(i, 0.05, size=len(data))  # jitter for visibility
    plt.scatter(x, data, s=12, alpha=0.5, color="orange", zorder=10)
plt.ylabel("SiO$_2$ (wt.%)")
plt.show()

The three groups have different spreads, the thin and medium groups are somewhat skewed with a few high values, but there is no extreme value and each group contains \(60\) cells. Since our theory concerns the mean SiO\(_2\) content, we use Welch’s one-way ANOVA for Step 1 and Welch’s t-tests for Step 2.

Question 1

Step 1: do the three means differ?

The hypotheses of Step 1 are

\[H_{0}: \mu_{\text{thin}}=\mu_{\text{medium}}=\mu_{\text{thick}} \quad \text{and} \quad H_{a}: H_0 \ \text{is false}.\]

Complete the code below to perform Welch’s one-way ANOVA (we consider \(\alpha = 0.05\)):

  • Exercise
  • Hints
  • Solution

The anova_oneway() (doc) function from statsmodels takes the variable to compare (sio2) and the variable defining the groups (crust_class). Which value of use_var allows the groups to have different variances?

Function reference: read_csv (doc); anova_oneway (doc); print (doc).

import pandas as pd
from statsmodels.stats.oneway import anova_oneway

crust = pd.read_csv("https://raw.githubusercontent.com/ELSTE-Master/Data-Science/main/Data/arc_magmas_crust_sample.csv")

# Welch's one-way ANOVA: SiO2 content by crustal-thickness class
res = anova_oneway(crust["sio2"], groups=crust["crust_class"], use_var="unequal", welch_correction=True)

print(f"F statistic = {res.statistic:.3f}")
print(f"p-value = {res.pvalue:.3g}")

You should obtain a p-value of about 1.1e-06, far below \(5\%\): we reject \(H_0\), the mean SiO\(_2\) content is not the same in the three classes, and we move on to Step 2.

Question 2

Step 2: which means differ?

We now consider the three one-sided tests that correspond to our theory:

Test 1: \(H_{0}: \mu_{\text{thin}}=\mu_{\text{medium}}\) and \(H_{a}: \mu_{\text{thin}} < \mu_{\text{medium}}\).

Test 2: \(H_{0}: \mu_{\text{medium}}=\mu_{\text{thick}}\) and \(H_{a}: \mu_{\text{medium}} < \mu_{\text{thick}}\).

Test 3: \(H_{0}: \mu_{\text{thin}}=\mu_{\text{thick}}\) and \(H_{a}: \mu_{\text{thin}} < \mu_{\text{thick}}\).

Complete the code below to perform the three tests at the Bonferroni-corrected level \(\alpha_c\). Pay attention to the order of the two samples in each call: with alternative="less", the alternative is that the mean of the first sample is smaller.

  • Exercise
  • Hints
  • Solution

With the Bonferroni correction, \(\alpha_c = \alpha / k\) where \(k\) is the number of tests. For the ttest_ind() (doc) function, alternative="less" tests whether the mean of the first sample is smaller than the mean of the second one. Test 3 compares the thin and thick classes.

Function reference: read_csv (doc); stats.ttest_ind (doc); print (doc).

import pandas as pd
from scipy import stats

crust = pd.read_csv("https://raw.githubusercontent.com/ELSTE-Master/Data-Science/main/Data/arc_magmas_crust_sample.csv")

# Variables of interest
sio2_thin   = crust["sio2"][crust["crust_class"] == "thin"]
sio2_medium = crust["sio2"][crust["crust_class"] == "medium"]
sio2_thick  = crust["sio2"][crust["crust_class"] == "thick"]

alpha_c = 0.05 / 3                                           # Bonferroni correction

# Test 1:  H0: mu_thin = mu_medium    vs  Ha: mu_thin < mu_medium
p_1 = stats.ttest_ind(sio2_thin, sio2_medium, alternative="less", equal_var=False).pvalue
# Test 2:  H0: mu_medium = mu_thick   vs  Ha: mu_medium < mu_thick
p_2 = stats.ttest_ind(sio2_medium, sio2_thick, alternative="less", equal_var=False).pvalue
# Test 3:  H0: mu_thin = mu_thick     vs  Ha: mu_thin < mu_thick
p_3 = stats.ttest_ind(sio2_thin, sio2_thick, alternative="less", equal_var=False).pvalue

for name, p in [("Test 1 (thin < medium) ", p_1), ("Test 2 (medium < thick)", p_2), ("Test 3 (thin < thick)  ", p_3)]:
    print(name, " p-value =", f"{p:.2e}", " -> reject H0" if p < alpha_c else " -> do not reject H0")

Question 3

What can we conclude?

You should obtain p-values of 1.75%, 0.26% and 7.9e-08 for Tests 1, 2 and 3, to be compared with \(\alpha_c = 0.05/3 \approx 1.67\%\) (the Dunn–Šidák correction would give \(1.70\%\) and the same decisions). At the significance level of \(5\%\) for the whole family of tests, we can conclude that:

Our subsample has the size of a typical field study. If you redo the analysis with the full compilation of Farner & Lee (2017) (replace arc_magmas_crust_sample.csv by arc_magmas_crust.csv in the import), the mean SiO\(_2\) contents are \(57.1\), \(56.9\) and \(61.2\) wt.% for thin, medium and thick crust: the p-values of Tests 2 and 3 are below \(10^{-88}\), but the p-value of Test 1 is \(88\%\).
